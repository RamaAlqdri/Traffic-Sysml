# Smart Traffic Light MBSE Starter

Starter configuration untuk proyek lokal.

## Cara memakai

1. Copy isi folder ini ke root repository proyek Anda.
2. Pertahankan folder `references/` yang sudah berisi 3 jurnal.
3. Berikan isi `MASTER_PROMPT.md` sebagai initial task kepada Codex.
4. Pastikan Codex membaca `AGENT.md`.
5. Pastikan Codex benar-benar menggunakan skill:
   - `academic research`
   - `ponytail`
6. Pantau progres melalui `logs/`.

## Expected final output

- `report/main.tex` + compiled PDF
- `presentation/main.tex` + compiled PDF
- Mermaid Requirement Diagram
- PlantUML behavioral/structural diagrams
- traceability matrix
- literature review
- verification scenarios
- build and progress logs

## Important

Starter ini tidak menyentuh folder `references/`.
